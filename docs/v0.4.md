# Выпуск Kremen 0.4.0

Основное изменение — рабочий bootstrap-тулчейн с компилятором и CLI, написанными на Kremen. Команда `kremen selfhost` подключает этот отдельный frontend к обычной установке. Самопересборка проверяет C-исходники компилятора и драйвера следующей стадии до публикации результата.

Bootstrap теперь сам проверяет типы `i64`, `bool`, `string`: объявления, присваивания, аргументы, операторы, условия и возвраты. Проверяются имена, арность, области видимости, дубли, точка входа, литералы и возврат на всех путях. Неявное преобразование `bool` в число не допускается даже там, где его принял бы C backend. Эти проверки реализованы в `bootstrap.kr`.

Драйвер `toolchain.kr` реализует `check`, `emit-c`, `build`, `run`, `bootstrap`. C-модуль `host.c` предоставляет только операции ОС: отдельные аргументы процесса, запуск без shell, файлы, временные каталоги и поиск ресурсов. Генератор кода и политика сборки находятся на Kremen.

```sh
make selfhost
./build/kremen selfhost check selfhost/example.kr
./build/kremen selfhost run selfhost/example.kr -- /tmp/kremen-example.txt
./build/kremen selfhost bootstrap -o build/kremen-selfhost-next
```

Новый инсталлятор устанавливает `kremen-selfhost` и исходники для его пересборки. Защита выходных файлов учитывает пути, симлинки и жёсткие ссылки; ошибка frontend/backend сохраняет предыдущий артефакт. Временные файлы убираются при диагностическом завершении процесса. Пользовательские аргументы передаются буквально, статус дочернего процесса сохраняется.

Исправлены зависание на FIFO-исходниках в обоих frontend, конфликты допустимых имён с C-заголовками и искажение строк триграфами C11. Эти случаи покрыты отдельными регрессиями.

Полный язык основного компилятора не меняет синтаксис 0.3. Его frontend остаётся на C. В bootstrap пока нет структур, `enum`, `defer`, срезов и проверок заимствований. Собственные frontend и driver подмножества воспроизводятся, но это ещё не полный self-hosting всех возможностей языка. C toolchain и libc остаются зависимостями.

Подробное использование и дальнейший путь к системному программированию: [selfhosting.md](selfhosting.md). Проверки: [validation.md](validation.md). Предыдущие возможности: [v0.3.md](v0.3.md).
