# Переход с Kremen 0.2 на 0.3.0

Это историческая страница, обновлённая для текущего пакета 0.4.0. В версии 0.2 появились нативный C11-компилятор, Asm/C-копирование буферов, локальные `import`, API-файлы `.krh`, результаты `!T` с `?`, срезы и форматтер. Эти возможности сохраняются.

Версия 0.3 добавляет `defer`, `catch`, арены, файловые операции, `enum`, `match` и кортежи. Имена новых ключевых слов и типов `arena`/`file` теперь зарезервированы. Историческая реализация и тесты на Python больше не поставляются; команды `python -m kremen`, `make legacy-test` и benchmark `--legacy` не применимы.

Актуальные страницы:

- [Установка](install.md).
- [Справочник языка](language.md).
- [Изменения 0.3](v0.3.md).
- [Проверки текущего выпуска](validation.md).

Основной компилятор остаётся на C; отдельный bootstrap на Kremen описан в [selfhost/README.md](../selfhost/README.md). Переименование версии не означает полного self-hosting.
