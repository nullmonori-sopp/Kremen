# Moving on from Kremen 0.2

Version 0.2 introduced the native C11 compiler, strict warnings, local modules and `.krh` headers, `!T` results with `?`, dynamic slices, formatting, and a bootstrap compiler for a separate subset.

The current release is 0.4.3. Its full language adds block-scoped cleanup, result fallbacks, arenas, filesystem operations, enums, matching, tuples, and independent worker threads. The subset has its own typed command-line toolchain. It still does not implement every feature of the full C frontend.

Use `build/kremen` after `make`, or install the `kremen` command. Historical `python -m kremen`, `make legacy-test`, and benchmark `--legacy` commands were removed with the Python implementation. The package contains no Python implementation or runtime dependency.

For an older project, check whether local names collide with the keywords and resource types introduced in 0.3. Read [0.3 notes](v0.3.md), then [0.4.1 notes](v0.4.1.md) for tightened borrowing and raw-pointer checks. Current installation and syntax are documented in [Installation](install.md) and the [language reference](language.md).
